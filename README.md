# Greenhill Food Co‑op - Online Ordering System
> Custom online ordering system for Greenhill Food Co‑op.
Core modules: member management, product management(unit & per‑kg pricing), order management, business view & reports.

## Project Background
Greenhill Food Co‑op is a local non‑profit food cooperative.
This system replaces manual spreadsheet work, digitizes member, product, order and sales report workflow.

## Main Features
1. Member Management: create, edit, query member records
2. Product Management: fixed‑price and per‑kilogram weight‑based pricing
3. Order Management: create, modify, full‑track order status
4. Views & Reports: multi‑dimension business statistics
5. Local/server deployment supported
